# Network Troubleshooting & Connectivity Diagnostics

## Project Overview
This project demonstrates practical network troubleshooting and connectivity diagnostics relevant to IT Support and Service Desk roles. The project focuses on identifying, analyzing, and resolving common network-related issues using Linux networking tools and TCP/IP concepts.

The project was performed in a Linux environment using Ubuntu and VirtualBox to simulate real-world troubleshooting scenarios commonly handled by Service Desk Engineers.

---

# Objective

The objective of this project is to:

- Understand TCP/IP networking fundamentals
- Practice connectivity troubleshooting techniques
- Diagnose DNS and network communication issues
- Learn network diagnostic commands used in IT support
- Document troubleshooting procedures professionally
- Build practical networking knowledge for Service Desk roles

# Commands Practiced

| Command | Purpose |
|----------|----------|
| ifconfig | Display network interface configuration |
| ip addr | View IP address details |
| ping | Test network connectivity |
| nslookup | Check DNS resolution |
| traceroute | Trace network path |
| netstat | Display active network connections |
| ssh | Remote system access |
| scp | Secure file transfer |

---

# Troubleshooting Scenarios Performed

## 1. Internet Connectivity Testing
- Verified internet connectivity using ping command
- Identified successful and failed packet transmission

## 2. DNS Troubleshooting
- Diagnosed DNS resolution failures
- Tested hostname resolution using nslookup

## 3. IP Configuration Verification
- Checked assigned IP addresses and network interfaces
- Verified active network adapter configuration

## 4. SSH Connectivity Troubleshooting
- Diagnosed SSH connection refused errors
- Verified SSH service status and port availability

## 5. Network Path Analysis
- Traced packet route using traceroute command
- Understood intermediate network hops
