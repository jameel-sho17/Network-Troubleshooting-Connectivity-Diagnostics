# Network Troubleshooting & Connectivity Diagnostics

## Project Overview

This project demonstrates practical network troubleshooting and connectivity diagnostics performed in both **Linux (Ubuntu)** and **Windows** environments. The project focuses on identifying, analyzing, and resolving common network, connectivity, DNS, and system-related issues using industry-standard troubleshooting tools and TCP/IP networking concepts.

The project was conducted using Ubuntu Linux, Windows 11, VirtualBox, and command-line diagnostic utilities to simulate real-world IT Support and Service Desk troubleshooting scenarios.

---

## Objective

The objective of this project is to:

* Understand TCP/IP networking fundamentals
* Troubleshoot network connectivity issues
* Diagnose DNS resolution problems
* Verify IP addressing and routing configurations
* Practice Windows and Linux administration commands
* Analyze network communication paths
* Document troubleshooting procedures professionally
* Build practical skills required for IT Support and Service Desk roles

## Troubleshooting Scenarios Performed

### 1. Internet Connectivity Testing

* Verified internet connectivity using `ping`
* Diagnosed packet loss issues
* Validated gateway communication

### 2. DNS Troubleshooting

* Diagnosed DNS resolution failures
* Verified hostname resolution using `nslookup`
* Cleared DNS cache and revalidated connectivity

### 3. IP Configuration Verification

* Checked assigned IP addresses
* Verified subnet masks and default gateways
* Confirmed network interface status

### 4. SSH Connectivity Troubleshooting

* Diagnosed SSH connection failures
* Verified SSH service availability
* Tested remote login functionality

### 5. Remote Desktop Connectivity

* Tested Windows Remote Desktop connections
* Verified network reachability between systems
* Checked firewall and port accessibility

### 6. Network Route Analysis

* Traced packet routes using `traceroute` and `tracert`
* Identified intermediate network hops
* Analyzed routing paths

### 7. Packet Loss Investigation

* Used `pathping` and `ping` utilities
* Identified latency and packet loss issues

### 8. Active Connection Monitoring

* Examined active network sessions using `netstat`
* Reviewed listening ports and established connections

### 9. Firewall and Adapter Troubleshooting

* Verified firewall configurations
* Enabled and disabled network adapters
* Investigated connectivity restrictions

### 10. User and System Administration

* Reviewed local user accounts
* Collected system information
* Managed shared resources and services
